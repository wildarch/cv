\section{Notable Projects}
\cventry{2023 -- present}{The GraphAlg Language}{}{}{\href{https://wildarch.dev/graphalg/}{wildarch.dev/graphalg}}{
    GraphAlg is a domain-specific programming language for graph algorithms that is designed to be integrated into existing database systems.
    It is natively supported in the AvantGraph graph query engine, with additional backends available for the relational systems Umbra and DuckDB.
    GraphAlg takes existing theoretical works, such as the formal MATLANG language for matrix manipulation, and turns these into practical extensions of real database systems, with a focus on achieving high performance through aggressive query optimization.
    %More details can be found in the SIGMOD 2027 paper \emph{Algorithm Support for Graph Databases, Done Right}.
    The GraphAlg compiler, as well as the online playground and tutorial, are open source software.
}
\cventry{05/08 2026}{Iteration in Relational Database Systems}{Technical University of Munich}{Munich}{}{
    During a 3-month research visit at the chair for database systems I investigated how queries with loops can be represented, optimized and executed efficiently in a modern relational query engine.
    I designed a highly flexible loop construct for SQL that subsumes multiple existing proposals, yet is simple enough to be implemented with minimal engine changes.
    The prototype, implemented in the Umbra database system, outperformed competing relational, graph-native and Datalog systems on both graph analytics and Datalog workloads.
    This work was the basis for a CIDR publication, and is now available in standard Umbra releases.
}
